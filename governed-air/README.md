# Governed Air — classroom demonstrator v0.1

Private development branch only. All readings and authority records are hypothetical. No real-world approvals, medical conclusions, regulatory compliance, or equipment control.

Run locally: `node --test governed-air/decision-engine.test.mjs` (Node 20+).

The decision engine is an illustrative policy fixture, not a complete implementation of TA14 admissibility, standing, or jurisdiction-specific requirements. The 1500 ppm example condition is an arbitrary teaching trigger, **not** a health or regulatory threshold. ALLOW is limited to a bounded investigation in the simulation. Physical control stays HOLD pending separate site-specific authorization.
