## Exchange ingestion and custody rules

1. Resolve each publication's record ID, DOI, version, exact title, files, checksums and license; do not infer them from titles.
2. Mirror **open** files only after verifying license and byte hashes; preserve original bytes and citation metadata, with no silent edits.
3. For **restricted** records, retain metadata and access controls; do not place PDFs in `public/`, client bundles, search indices, or open object buckets.
4. Keep a publication-version ledger and immutable origin references; never silently replace a frozen baseline.
5. Provide a searchable corpus interface only after permission-aware access paths and provenance are implemented.
6. Track software state separately: `specified`, `simulated`, `implemented`, `tested`, `independently verified`, and `operationally validated`; never infer one from another.
7. Do not automatically publish or deploy this branch.
