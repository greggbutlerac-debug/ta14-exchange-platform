# 1. Purpose

The TA-14 Reviews & Responses Index provides the institutional discovery layer for
attributable reviews, responses, challenges, corrections, technical comments,
external publications, replication requests, demonstration requests, and governed
communications associated with records preserved through the TA-14 AI Governance
Exchange.

This index does not replace the underlying records.

It provides a structured map to them.

The underlying record remains authoritative for its own content, authorship,
chronology, evidence, status, and institutional boundaries.

---

# 2. Governing Principle

The TA-14 AI Governance Exchange preserves separate voices.

The Exchange may contain:

- TA-14 findings;
- Participant Reviews;
- Participant Responses;
- Independent Reviews;
- Evidence Challenges;
- Factual Corrections;
- Technical Comments;
- Replication Requests;
- Demonstration Requests;
- External Publications;
- Governed Messages.

These records may address the same governance event without becoming the same
institutional voice.

The purpose of this index is to make those relationships inspectable.

---

# 3. Record Relationship Model

A mature governed record may develop through the following sequence:

**Registered Baseline**  
→ **Governance Profile**  
→ **Frozen Implementation**  
→ **Governed Demonstration**  
→ **Admitted Evidence**  
→ **Execution Artifact**  
→ **TA-14 Finding**  
→ **Participant Review**  
→ **Participant Response**  
→ **Independent Review**  
→ **Evidence Challenge**  
→ **Factual Correction**  
→ **Technical Comment**  
→ **External Publication**  
→ **Engineering Learning**  
→ **New Version**  
→ **New Registered Baseline**

Not every record will contain every stage.

Absence of a record class must not be interpreted as evidence that the corresponding
event occurred.
